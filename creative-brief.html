Section 1: Project DNA

Mission

Publish deeply honest daily diary entries that help process life experiences with calm, reflective storytelling.

  • Core purpose: emotional release and self-reflection
  • Depth level: very deep and vulnerable
  • Post cadence: daily, short-form entries

Audience

Readers who have lived similar experiences and seek grounded, intimate writing.

  • Public visibility enabled
  • Niche emotional resonance prioritized
  • Success metric: consistency first
Voice tags: calm / reflective / honest / first-person / diary-like / theme-based navigation

Section 4: Privacy and Safety Rules

Privacy Guardrails

  • Never publish exact addresses, workplaces, schools, or repeating route details.
  • Avoid exact timestamps for sensitive events; keep timing references broad.
  • Use role labels instead of full names for other people (example: a close friend).
  • Strip metadata from uploaded images before publishing.
  • Do not reuse private phrases used in other identifiable social accounts.

Pre-Publish Redaction Checklist

  • Check location references: city, district, street, venue, event names.
  • Check personal identifiers: names, phone numbers, unique job details.
  • Check media attachments for hidden metadata and recognizable backgrounds.
  • Check story combinations that could triangulate identity over time.
  • Check emotional safety: remove details that compromise future boundaries.
Public + SEO enabled, with anonymity protected through deliberate abstraction and review.

Visual Board Acceptance Criteria

  • Fits faded-film style without introducing modern glossy or neon visual language.
  • Maintains high readability for short daily posts on desktop and mobile.
  • Supports calm emotional pacing and does not distract from writing.
  • Contains no direct identity cues or visual references to personal locations.
  • Can be translated into reusable CSS tokens and stable UI components.

Execution Checklist

  2. Select one primary direction and one backup direction.

  4. Build MVP pages: homepage index, post page template, archive-by-theme view.
  5. Run a privacy redaction pass on all sample copy and media assets.
